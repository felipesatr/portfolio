# Components for future projects

This folder is the archive for complete components removed from the live site but worth keeping for reuse.

## Kind words layouts

When a Kind words layout is removed from the site, archive it in its own named folder under `kind-words/` (for example, `kind-words/01-compact-card/`). Keep its component code, layout-specific styles, assets, and a short README together there. The README should explain what the layout does and any steps needed to restore it. Shared helper and base-style snapshots used by these layouts live in `kind-words/_shared/`; the archive index is in `kind-words/README.md`.

Do not move shared code or assets out of the live site while another layout still depends on them. Copy only what the archived layout needs, and note shared dependencies in its README.

Archived Kind words layouts are grouped in `kind-words/` by their original layout number and descriptive name. Keep the original number in the folder name so the archive remains traceable to the live comparison. The live site currently retains layouts 01, 03, 04, 08, and 10.
